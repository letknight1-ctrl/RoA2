Rivals of Aether 2 Showcase
A fan-made Rivals of Aether 2 showcase website built with HTML and CSS. The website presents information about the game, its features, competitive scene, tournaments, and notable players from the 2025–2026 season.

Overview:
This project is a simple static website designed to introduce visitors to Rivals of Aether 2 and highlight its competitive platform-fighting scene.

The site includes:
- Game introduction
- Game features
- Trailer links
- Riptide Grand Finals video
- Player cards for notable Rivals of Aether 2 players

Technologies Used:
HTML5 — Website structure and content
CSS3 — Styling, layout, animations, and visual effects
YouTube — Embedded through external links
JPG/PNG — Website imagery

No frameworks or external libraries are required.
